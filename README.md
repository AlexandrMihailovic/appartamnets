# 999.md — недвижимость Кишинёва

Собирает объявления о продаже с карты 999.md в SQLite и показывает их в браузере:
списки с фильтрами, карта, история цен, помесячная динамика цен за квадратный метр.

Два профиля: квартиры и гаражи с парковками. Выборка задаётся обычной ссылкой
на карту 999.md в `profiles.py` — из её GET-параметров собираются фильтры запроса.

## Запуск

```bash
python3 -m pip install -r requirements.txt
python3 collect.py      # список объявлений
python3 details.py      # карточки: площадь, этаж, координаты, фото
python3 app.py          # дашборд, http://127.0.0.1:8777
```

Обновление по кругу в фоне: `python3 watch.py` (`--status`, `--stop`, `--interval 15`).

Нужны Python 3.10+ и SQLite 3.25+, из внешнего — только `requests`.

## Дашборд

Вкладки: **Выгодные** (дешевле медианы сопоставимых) · **Новые** · **Подешевели** ·
**Все** · **Избранное** · **Скрытые** · **Статистика** · **Динамика** (помесячный тренд цен).
Список и карта, фильтры по цене, площади, комнатам, этажу, сектору, жилому фонду и автору.

Персональные данные продавцов в интерфейс не отдаются: показывается только тип автора —
агентство, застройщик или частное лицо.

## Файлы

| Файл | Назначение |
|---|---|
| `profiles.py` | что собираем: ссылки-фильтры и подкатегории |
| `db.py` | схема SQLite |
| `collect.py` | сбор списка + отчёт об изменениях |
| `details.py` | сбор карточек в несколько потоков |
| `watch.py` | фоновое обновление по кругу |
| `app.py` | веб-сервер дашборда, только стандартная библиотека |
| `static/index.html` | весь интерфейс одним файлом |
| `scrape_999.py` | выгрузка списка в CSV, отдельно от базы |
| `scrape_ad.py` | разбор одного объявления в JSON/CSV |
